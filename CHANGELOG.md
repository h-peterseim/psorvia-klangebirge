# Changelog

## 1.0.1 (proposed)
- Two more README translations: Norwegian Bokmål (`nb`) and Turkish (`tr`).

## 1.0.0
- First release: web component `<klang-gebirge>`, as ES module and classic script.
- Audio-reactive wireframe mountain range: bass shapes broad massifs, treble narrow peaks; a flight through a valley.
- Attributes for colors (dark and light scheme), opacity, reactivity, horizon, audio source, text fading, frame-rate limit, curves, hills and course.
- Still image with reduced motion, rest without music, pause in hidden tabs, fallback without WebGL.
- Demo page with music by PSOrvia plugins (CC BY 4.0).
